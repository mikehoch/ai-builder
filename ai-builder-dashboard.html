Leland Messages: Daily Brief
Scoped May 4, 2026  ·  Area: Leland  ·  Priority: High
⚡ In Progress
An on-demand Claude agent that opens joinleland.com in your browser while you're already logged in, reads every message thread active in the last 7 days, classifies each contact (new lead / warm lead / active client), applies urgency logic, and returns a structured brief with three sections: a priority action list, per-contact summaries with draft replies, and a full status table. Run it on demand; output lands directly in Claude's response to copy and edit from.
Sub-build 1 · v1 Focus
Inbox Scraper
Claude in Chrome navigates joinleland.com/inbox, clicks into each thread, and returns raw structured data: contact name, timestamps, and full message text per thread.
Est. 1–2 hours
Sub-build 2
Classifier + Brief Generator
Classifies each contact, applies urgency logic (Urgent / Recommend reply / No reply needed), generates context summaries, and drafts a reply for every thread that needs one.
Est. 1 hour
Sub-build 3 · Future
Packaged Runner
Combines scrape + brief into a single slash command or scheduled agent. Adds push delivery.
Out of scope for v1
Starting Prompt — Sub-build 1
I want to build a Leland inbox scraper using Claude in Chrome. Goal: Navigate to https://www.joinleland.com/inbox while I'm already logged in, read every visible message thread, click into each one to capture the full conversation history, and return structured data for each thread: contact name, date of most recent message, and the full message text in chronological order. Scope for this first version: - Only threads with activity in the last 7 days - Click into each thread to get full message content (not just previews) - Return raw data as a structured list — no summarizing yet, just extraction - If a thread can't be read or navigation fails, note it and continue Start by navigating to joinleland.com/inbox, taking a screenshot, and describing what you see. Then we'll map the navigation pattern before writing any automation logic.
Out of v1 Auto-sending drafts  ·  Scheduled runs  ·  HubSpot sync  ·  Attachment handling  ·  Inbox pagination  ·  Custom interface
